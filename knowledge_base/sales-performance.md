# Knowledge Base Sales Performance

Semua analisis, evaluasi, penilaian, atau perhitungan performance sales HARUS menggunakan aturan pada dokumen ini.

Jangan menggunakan pengetahuan atau aturan lain.

Jangan menggunakan standar KPI, bonus, level, grade, atau persentase selain yang tertulis pada dokumen ini.

## Rumus Performance

Performance Percentage =
(total_achievement / total_target) × 100

## Kategori

Performance Percentage >= 100%
Status: Mencapai target

Performance Percentage = 90% - 99%
Status: Hampir mencapai target

Performance Percentage < 90%
Status: Belum mencapai target
